# Security Policy

## Report a vulnerability privately

Please email [support@aidictation.com](mailto:support@aidictation.com) with:

- The affected platform and app version.
- A clear description of the issue and its impact.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.

Do not include real recordings, transcripts, credentials, access tokens, payment information, or other personal data. Use synthetic examples.

Please do not open a public GitHub issue until the problem has been investigated and a safe disclosure timeline has been agreed.

## Supported versions

Security fixes are applied to current releases. Before reporting an issue, check the [latest downloads](https://aidictation.com/download) and [GitHub Releases](https://github.com/writingmate/aidictation/releases).

## Public bugs

Use [GitHub Issues](https://github.com/writingmate/aidictation/issues) for ordinary bugs that do not expose sensitive data or create a security or privacy risk.
