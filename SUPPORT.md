## Common Setup Help

### Enable the iOS Keyboard

1. Open iPhone Settings.
2. Go to General > Keyboard > Keyboards.
3. Add AI Dictation.
4. Turn on Allow Full Access so the keyboard can start voice input and return text.

### Microphone Access

Open iPhone Settings > Privacy & Security > Microphone and allow AI Dictation.

### Cloud and Offline Modes

Cloud mode sends your voice recording and generated transcript to AIDictation's cloud transcription service. That service sends recordings to Groq to create transcripts. The app asks before cloud mode sends audio or transcripts.

Offline mode keeps transcription on your device where it is available.
