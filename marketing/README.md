# AI Dictation Promotion Workspace

This directory contains reusable, evidence-based promotion assets for AI
Dictation. Product claims must stay consistent with the root README and current
shipping behavior.

## Daily Video Program

- [`video-keyword-calendar.md`](video-keyword-calendar.md) contains the first
  30 keyword-led episodes and claim guardrails.
- [`video-performance-log.csv`](video-performance-log.csv) records review,
  publication, retention, discovery, and website-click results.
- Each dated folder under `videos/` contains its script, sources, Remotion
  project, YouTube metadata, and locally ignored render output.
- Every video is uploaded as **unlisted** first. It becomes public only after
  product-owner review and approval.

## Repository Discovery

The default branch uses a keyword-led root README, an accurate GitHub
description, the canonical `https://aidictation.com` homepage, and all 20
available repository-topic slots. The topic set covers the product's verified
platforms, open-source license, speech-to-text use cases, offline recognition,
personal vocabulary, and implementation languages. Last audited: August 2,
2026.

## Promotion Rules

- Disclose project affiliation on self-submissions.
- Prefer dated proof and reproducible demonstrations over superlatives.
- Say “supported text fields,” not “every app.”
- Say “offline recognition on supported devices,” not “fully offline
  everywhere.”
- Recheck pricing, versions, competitor facts, platform behavior, and directory
  rules on the publication date.
- Do not publish personal data, customer recordings, private transcripts,
  credentials, or non-public analytics.
