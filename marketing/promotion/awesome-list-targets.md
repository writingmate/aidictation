# AI Dictation Awesome-List Submission Queue

Research snapshot: August 2, 2026.

The repository now has a public root MIT license and an SEO-focused README on
its default branch. Use this factual base description unless a list requires a
different format:

> Cross-platform voice-to-text app with MIT-licensed native client source,
> offline recognition on supported devices, and optional cloud transcription
> and cleanup.

Every self-submission should disclose the project affiliation. Use “freemium /
open source,” not “freeware,” and do not imply that the complete workflow is
offline on every platform.
